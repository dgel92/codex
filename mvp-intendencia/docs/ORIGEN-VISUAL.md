- Todos los archivos nuevos del MVP están bajo `mvp-intendencia/`.
- No se modifican ni reemplazan archivos existentes de `frontend/`, `backend/`, `Maqueta/` o el README principal.

Se reutilizan copias de los logos `logo-st.png`, `logo-ct.png` y la imagen `banner-principal.png`, guardadas dentro de `static/branding/`. El estilo de acceso se basa en una copia del CSS de `frontend/src/app/pages/login/login.css`. El panel sigue la paleta y organización de `frontend/src/styles.css`, el layout administrativo y las tablas de productos: rojo #e72d07, fondo gris claro, barra lateral #212121 y botones rojos.

La implementación funcional corresponde al MVP académico de Intendencia HU-01 a HU-06. Tiene Flask/SQLite propios y no depende de modificar ni de ejecutar el Angular o el Django del equipo. La aplicación independiente facilita la exposición mientras el proyecto principal continúa su desarrollo. Las capturas, el video y la presentación de esta carpeta muestran esta versión con estética EasyStock.
